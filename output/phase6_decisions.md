## Phase 6 (timebox started 2026-10-26 01:43)
4. **"Low temperature" isn't available:** `gpt-6-luna` is a reasoning model; the API ignores `temperature` (pydantic-ai warns "Sampling parameters ['temperature'] are not supported when reasoning is enabled"). Consistency comes instead from (a) explicit concession rules in the negotiator prompts, (b) the code rules that bound every move, and (c) demo pairs whose outcome is forced by the limits (no overlap → walk-away/round cap; wide overlap → deal). Repeat runs measure how consistent it is. **Q:** you asked for low temperature; this is the closest equivalent.
5. **Two human approvals:** a deal now needs the seller's AND the buyer's approval (each company approves its own side, e.g. by switching demo accounts). Either side can reject; reject closes the negotiation and puts the listing back on the market.
6. **Negotiation entry points:** "Start negotiation" on match alerts (bell), on Buy-page matches, on Sell-page buyer matches with an open need, and a "Ready to negotiate" list on the Negotiations tab (your listings × open requests they fill, and vice versa, from the same pre-filter code). The list is what a real user would want ("deals I could start"), and it gives seeded listings/needs an entry point.
7. **Private limits:** the company that starts can review/adjust its own limit ("Only your agent sees this."). Locked while a negotiation using it is open. New listings get the pricing agent's suggested floor stored as their starting floor (the seller can change it before negotiating). A request posted without a max price can't be negotiated until the buyer sets one: if the seller starts, they see "the buyer hasn't set a budget yet". **Q:** alternative would be a default budget, but inventing a buyer's budget felt wrong.
8. **Message safety:** a message containing the agent's OWN limit is blocked (the agent must rewrite: existing rule). A message containing the OTHER side's limit (only possible by coincidence, since the agent never sees it) is **redacted silently** instead of blocked: blocking would tell the agent "you just hit the other side's number", which is itself a leak. Private rationales get the same redaction.
9. **Concurrency:** 3 negotiations run at once; more are opened (units locked) and shown as **Queued** until a slot frees.
10. **Demo samples (known outcomes from the seeded limits):** Hartwell: clear deal with Riverbend (listing 1 / need 1) and narrow deal with Prairie Packaging (listing 13 / need 13); Riverbend: the same clear deal from the buyer side; Summit: clear deal with Ironclad (12/12); Redwood: narrow deal with Coastal Electronics (15/15); **Cascade Paper & Board added as a 6th demo account** for the walk-away (11/11, the floor is above the buyer's budget). **Q:** none of the 5 featured accounts had a no-overlap pair, so I added one account rather than change seeded limits.
11. **Partial quantities:** a deal for fewer units than the listing has (Hartwell's 3 CPUs, Riverbend needs 1) sells those units; the rest stay on the market (listing qty 3 → 2, still active). "Listing sold" happens when the last unit is sold.
12. **Who approves:** the approver recorded is "<company> (demo user)", since accounts are a demo stand-in for sign-in.
13. **Next-best match** after a walk-away/round cap/rejection uses the same pre-filter code as matching (plus the match score if one exists), for the viewer's own side only.
14. **Queue display fix:** with five starts at the same instant, each one checked "is a slot free?" before any had taken one, so none showed as queued. A negotiation now shows "Queued" until it actually holds one of the 3 slots. The test measures this exactly (runs that waited for a slot; most runs making model calls at the same time) instead of polling five views one by one.
15. **Start order:** the API checks whether a negotiation can start *before* saving a changed limit, so a busy pair says "already in a negotiation" instead of "your budget is locked".
16. **Negotiator prompt fix (found by the repeat runs):** the narrow-deal sample (Hartwell → Prairie Packaging, floor $122 / budget $131) walked away 3/3 times: at round 6 the seller was at $140 and the buyer agent walked away ("seller stays above your ceiling late"), although a final offer at its budget could have closed. Both prompts now say: with your last offer, make your best offer within your limit; walk away only when no deal is possible (the other side's final offer is outside your limit). Trade-off: a final offer at your limit shows the other side a price you could pay — but that is an offer, the same as in any negotiation, not the stored limit.
