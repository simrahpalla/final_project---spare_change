How the agents work

Code runs the pipeline and calls gpt-6-luna only where judgment is needed: listing, compliance edge cases, matching, pricing, negotiating. Two human touchpoints: confirm your private limit, approve the deal. The MCP server is the only path to the data, with tools by role. The detailed diagram is in the report.
