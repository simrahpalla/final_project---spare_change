Automa sells the same goods by part number; SPARETECH has the parts data and resells via partners; Pactum negotiates for buyers on new procurement. We combine compatibility matching, two-sided agent negotiation with code-enforced limits, and a human-approved close.

How the agents work

Code runs the pipeline and calls gpt-6-luna only where judgment is needed. Two human touchpoints: confirm your private limit, approve the deal. The MCP server is the only path to the data, with tools by role.
